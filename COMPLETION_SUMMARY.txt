                            QUICK START GUIDE
================================================================================

1. INSTALL DEPENDENCIES
   $ npm install

2. START DEVELOPMENT SERVER
   $ npm run dev
   
   Opens automatically at http://localhost:3000

3. EDIT YOUR PORTFOLIO
   Open: src/data/portfolio.json
   Update: Your name, email, phone, services, skills, projects, etc.

4. ADD IMAGES
   Place images in: src/assets/
   Reference in: src/data/portfolio.json

5. VALIDATE
   $ npm run validate

6. BUILD FOR PRODUCTION
   $ npm run build

7. DEPLOY
   Push to GitHub → Connect to Netlify/Vercel → Deploy

================================================================================
                        TROUBLESHOOTING
================================================================================

ISSUE: Port 3000 already in use
SOLUTION: Edit vite.config.js, change port to 3001

ISSUE: Images not showing
SOLUTION: Check filename matches portfolio.json, ensure image in src/assets/

ISSUE: JSON validation fails
SOLUTION: Run npm run validate to see errors, check JSON syntax

ISSUE: Styles not applying
SOLUTION: Restart dev server, clear browser cache

ISSUE: Build fails
SOLUTION: Check npm run validate passes, check for syntax errors

See README.md for more troubleshooting.
